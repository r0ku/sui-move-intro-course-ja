# Move 入門コース

[Sui Foundation](https://suifoundation.org/)が管理する Move 言語の入門コースです。

## 本リポジトリについて

本リポジトリは、[Sui Foundation](https://github.com/sui-foundation/sui-move-intro-course)が開発した英語版の Move 入門コースを日本語に翻訳したものです。

**元のリポジトリ**: [https://github.com/sui-foundation/sui-move-intro-course](https://github.com/sui-foundation/sui-move-intro-course)
